**Wording 1.** `In this game every player has a state, {a} or {b}. Player 1 can see the states of {n_peers} other players: {peers}.{memory} Reply with the state that Player 1 takes now, in JSON with the key "state".`

**Wording 2.** `Player 1 takes part in a game where each participant holds one of two states, {a} or {b}. The states of the {n_peers} players Player 1 can see are: {peers}.{memory} Give the state Player 1 should adopt now as a JSON object with the single key "state".`

**Wording 3.** `Each player in the game is in state {a} or in state {b}. Player 1 observes {n_peers} other players with these states: {peers}.{memory} State Player 1 should now be in, as JSON with one key called "state".`

**Wording 4.** `Consider Player 1 among a group of players whose state is either {a} or {b}. The current states of the {n_peers} players visible to Player 1 read: {peers}.{memory} Output the state Player 1 holds now as JSON containing only the key "state".`
